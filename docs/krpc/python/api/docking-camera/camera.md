# Camera

class Camera
:   A Docking Camera.

    part
    :   Get the part containing this camera.

        Attribute:
        :   Read-only, cannot be set

        Return type:
        :   [`SpaceCenter.Part`](../space-center/parts.md#SpaceCenter.Part "SpaceCenter.Part")

    image
    :   Get an image.
        Returns an empty byte array on failure.

        Attribute:
        :   Read-only, cannot be set

        Return type:
        :   bytes
